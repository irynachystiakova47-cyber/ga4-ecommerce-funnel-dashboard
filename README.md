# ga4-ecommerce-funnel-dashboard

GA4 Ecommerce Funnel Dashboard

Project Overview:

This project analyzes user behavior in an e-commerce store using Google Analytics 4 sample data from BigQuery.
The goal was to identify key conversion points in the customer journey and visualize the ecommerce funnel from session start to purchase.

Business Goal

Help marketing teams:

- monitor key ecommerce metrics;
- identify funnel drop-off points;
- compare conversion rates across traffic sources and user segments;
- support data-driven decision making.

Dataset:
- Source: Google Analytics 4 Sample Ecommerce Dataset
- Period: November 2020 – January 2021

Tools:
- SQL (BigQuery)
- Tableau Public
- Google Analytics 4 Dataset

Funnel Stages:
1. Session Start
2. View Item
3. Add to Cart
4. Begin Checkout
5. Add Shipping Information
6. Add Payment Information
7. Purchase

   
Dashboard Features:
- KPI metrics (Sessions, Purchases, Revenue, Conversion Rate)
- Conversion Funnel
- Traffic Source Analysis
- Device Analysis
- Country Analysis
- Interactive Filters


Project Structure:
- sql/ – SQL query used for data extraction and transformation
- presentation/ – project presentation
- images/ – dashboard screenshots
