# ga4-ecommerce-funnel-dashboard

GA4 Ecommerce Funnel Dashboard

Project Overview:
This project analyzes user behavior in an e-commerce store using GA4 data from BigQuery.

The goal was to build an interactive dashboard that helps marketing teams understand customer conversion through the purchasing funnel and identify factors affecting sales performance.

Business Questions:
- How many users visit the website?
- Where do users drop off in the purchase funnel?
- Which traffic sources generate the highest conversion rates?
- How do device types and user characteristics influence purchases?

Dataset:
- Source: Google Analytics 4 Sample Ecommerce Dataset
- Platform: BigQuery
- Period: November 2020 – January 2021

Tools Used:
- SQL (BigQuery)
- Tableau Public
- Google Analytics 4 Dataset

Funnel Stages:
1. Session Start
2. View Item
3. Add to Cart
4. Begin Checkout
5. Add Shipping Information
6. Add Payment Information
7. Purchase

Dashboard Features
Sales Metrics
Orders Metrics
Revenue Metrics
Conversion Funnel
Traffic Source Analysis
Device Analysis
Interactive Filters
